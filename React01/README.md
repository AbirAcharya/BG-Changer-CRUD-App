# BG Changer CRUD App

A simple, responsive React application built with Vite and Tailwind CSS that lets users dynamically change the screen's background color via a floating bottom control bar.

## Features
- **Dynamic Background Switching:** Instantly updates the viewport background color using React's `useState` hook.
- **Floating Control Dock:** Sleek, glassmorphic bottom pill bar with smooth hover and click transitions.
- **Responsive Design:** Styled with Tailwind CSS to work cleanly across desktop and mobile screens.

## Tech Stack
- **React** (Hooks / `useState`)
- **Vite** (Build tool & dev server)
- **Tailwind CSS** (Utility-first styling)
